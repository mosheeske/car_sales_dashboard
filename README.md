# 🚗 Car Sales Dashboard (Streamlit App)

## 📌 Overview
This project is an interactive web application that allows users to explore and visualize used car sales data. The dashboard enables dynamic analysis of key variables such as price and mileage, helping identify patterns and relationships in the dataset.

## 🎯 Objective
To build an interactive dashboard that facilitates exploratory data analysis (EDA) and provides insights into vehicle pricing and usage patterns.

## 🛠️ Tools & Technologies
- Python
- pandas
- Streamlit
- plotly-express

## 📂 Dataset
The dataset contains listings of used vehicles, including:
- Price
- Mileage (odometer)
- Vehicle characteristics

## 🔍 Features
- Interactive histogram of vehicle mileage
- Scatter plot of price vs mileage
- Dynamic visualization triggered by user input
- Simple and user-friendly interface for data exploration

## 📈 Key Insights
- Vehicles with lower mileage tend to have higher prices
- There is a clear negative relationship between mileage and price
- Data visualization helps quickly identify pricing trends and outliers

## 💡 Business Impact
This type of dashboard can help:
- Buyers understand fair pricing ranges
- Sellers position their vehicles competitively
- Businesses analyze market trends
- Support data-driven decision-making in automotive sales
